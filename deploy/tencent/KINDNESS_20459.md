## 默认 999 天与工具

偏好已写入根目录 `AGENTS.md`、`EVENTS.md` 及公共 `event_schedule.py`。
通用工具 `prepare_event.py` 与已有 `prepare_halloween.py` 均采用默认 999 天、活动及卡池同日起止。
`--end` 可明确覆盖共同结束时间，`--banner-end` 可单独覆盖卡池。历史排期不会自动延长。

```bash
python3 deploy/tencent/prepare_event.py \
  --event-id 20459 --banner-preset deploy/tencent/kindnessBanner.json \
  --start '2026-10-29T10:30:00+08:00' \
  --replace-event 20801 --replace-banner 1020003 \
  --out /workspace/work/next-events.json --banner-out /workspace/work/next-banners.json
```

默认只追加新排期；显式 `--replace-*` 才结束指定旧排期，不延长已经结束的历史记录。
不覆盖正式配置、输入、预设或已有输出，不连接服务器或自行部署。本期已在正式配置准备，不能再按默认输入重复追加同编号。
