## 以后决定上线时

1. 用户确定开始时间和时长。原版可游玩期为 9 天；脚本默认保留此时长，可用 `--end` 指定结束时间。
2. 在仓库根目录生成待上线文件，明确填写带时区的时间：

   ```bash
   python3 deploy/tencent/prepare_halloween.py \
     --start '<确定的北京时间，格式 YYYY-MM-DDT14:00:00+08:00>' \
     --out /tmp/halloween-staged.json
   ```

   审阅新增 20801 的时间，并确认 20401、卡池与其他设置不变，再将审阅后的文件替换正式配置。
   这个替换应在待上线分支中完成，不能直接改生产服务器。
3. 按 [EVENTS.md](EVENTS.md) 再生成并读回五语言资源、运行检查；实际排期改变后，资源版本会重新生成。
4. 用户要求上线后才合并并使用 **Deploy to Tencent Cloud**，然后 TAT 只读核对镜像、资源和服务健康。
5. 手机彻底退出重开，按以下清单记录结果和时间，不提前勾选：

   - [ ] 入口、活动页、5 段剧情与点心之家领取/摆放正常。
   - [ ] 代表剧情图、每日关、Boss 高级、EX、挑战关分别进图、通关和结算正常。
   - [ ] 三种活动道具/材料、积分及首通/重复奖励，与背包前后差额对应。
   - [ ] 限定与每日任务、积分领奖、商店兑换、限额正常。
   - [ ] 支持联机的普通关卡双人进图、行动、双方结算及返回准备后续战正常。

准备分支和离线测试不会触发生产部署。本次没有手机验收结论，也没有线上资源版本变更。
